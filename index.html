⚙️ 연결 설정

Google Sheets API로 응답 시트를 주기적으로 읽어옵니다.

처음이신가요? 설정 방법
  1. 구글폼 → 응답 탭 → 시트 아이콘으로 스프레드시트 연결
  2. 그 시트 → 공유 → 링크가 있는 모든 사용자 = 뷰어
  3. console.cloud.google.com → 프로젝트 생성 → Google Sheets API 사용 설정
  4. 사용자 인증 정보 → API 키 만들기 → 키 복사 (HTTP 리퍼러 제한 권장)
  5. 위 칸을 채우고 열 불러오기 → 질문 선택 → 저장
